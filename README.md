# INSYT.

**Intelligent Financial Clarity** — an AI-powered personal finance platform built with Next.js, Supabase, and Claude.

---

## Overview

INSYT. gives you complete financial visibility with AI that thinks alongside you. Track income, expenses, debt, and savings goals — then let INSYT generate personalised insights and answer questions about your finances in plain language.

Works instantly as a guest (no account required) or with a full account to sync data across devices.

## Features

- **Financial dashboard** — health score, cashflow overview, budget progress, debt tracking
- **INSYT AI insights** — Claude-powered analysis of your financial data, cached and refreshed on demand
- **INSYT AI chat** — conversational coach that answers questions about your specific finances
- **Debt strategy** — payoff planner with avalanche/snowball comparisons
- **Budget tracking** — income and expense management with category breakdown
- **Savings goals** — progress tracking toward targets
- **Guest mode** — full functionality with local state, no signup required
- **Dark / light mode** — system-aware with manual toggle

## Getting Started

### Prerequisites

- Node.js 18+
- A [Supabase](https://supabase.com) project
- An [Anthropic](https://console.anthropic.com) API key

### 1. Install dependencies

```bash
npm install
```

### 2. Configure environment variables

Create a `.env.local` file at the root:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
ANTHROPIC_API_KEY=your-anthropic-api-key
```

### 3. Run database migrations

Apply the migrations in order using the Supabase dashboard SQL editor or CLI:

```bash
supabase/migrations/001_schema.sql      # Core schema
supabase/migrations/002_insights_cache.sql  # Insights caching
```

### 4. Start the dev server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## AI Insights Caching

Insights are generated by Claude and cached in Supabase with a 24-hour TTL. A SHA-256 fingerprint of the user's financial data triggers a cache miss when anything changes — so API calls only happen when the data actually changes or the user forces a refresh.

## Environment Notes

- The app defaults to **dark mode**; theme preference is persisted in `localStorage`
- Guest mode stores all data in memory via the finance store — nothing is sent to the server unless the user is authenticated
- AI chat streams responses using the Vercel AI-style SSE format
